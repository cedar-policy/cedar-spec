`Expr::try_from(Residual)` is type-erasing by construction: all 13 arms of `convert_residual` bind `ty` with `..` and none of them reads it, and `pst::Expr` has no annotation slot to carry a type in. That is the right call for the TPE target, where the question is whether both sides evaluated to the same residual and the typing was already settled upstream. For #840 the annotation is the object under test, so routing both sides through `pst::Expr` would compare the erasure of the thing being compared: if Rust annotates the `1` in `context.amount < 1000` as `Long` and Lean annotates it `Bool`, the trees are structurally identical, both project to `pst::Expr::Lit(Long(1))`, and the assertion passes. Rust's `Option<Type>` against Lean's total `CedarType` is the sharper case, since with no annotation slot `None` and `Some(Bool)` are the same value in the target type. Decoding the Lean tree into `Expr<Option<Type>>` does keep the types, because educe leaves `data` in `PartialEq`, but it relocates the problem rather than removing it: the decoder has to fix which Rust `Type` each Lean `CedarType` denotes, which is the correspondence under test, and a disagreement then arrives as a conversion `Err` behind `.expect("...should succeed")`, filed as harness breakage instead of as a divergence. So I render each side independently into a small neutral node type and carry `ty` as a compared field. I did take the surrounding pattern from `tpe.rs`: matching by policy id with an explicit report when one side has a key the other lacks, the `assert_eq!` failure-message shape, and `(Err(_), Err(FfiError::LeanBackendError(_)))` treated as agreement on rejection. One correction to my earlier comment: I said I would surface `Like` and `Is` as shape mismatches and I have flipped that, because folding the Rust variants into Lean's `unaryApp` shape can be declared as a normalisation and tested (the matching case agrees, a differing pattern is still caught), whereas the alternative reports a mismatch on every policy that uses `like`. Happy to restructure any of this.
